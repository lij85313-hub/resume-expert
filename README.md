# 简历专家

✏️ 帮应届生把简历改得更清楚、更具体，也把每次修改的过程留下来。

这是一个装在你自己电脑上的小工具。把岗位要求和现在的简历贴进去，它会帮你看差距、改写法，并准备可能被问到的问题。

这一版加入了 **历史分析、长期记忆和简历版本对比**。分析结束后自动保存，下次打开可以继续看；换了新版简历，也能对照之前的问题检查修改效果。

## 🧰 你需要准备

- 一台电脑。双击启动窗口只适用于 Windows；Mac 可以用下面的提示词让 AI 帮你启动。
- **Node.js 22.13 或更高版本**。建议安装满足这个要求的 LTS 版本，历史功能需要用到内置 SQLite。
- 一个大模型的 API Key，由你自己申请并在网页中填写。

## 🚀 第一次打开

先在本仓库页面点击绿色的 **Code**，选择 **Download ZIP**，下载后解压。

### Windows

1. 把下面这段话复制给你的 AI 助手（Codex、豆包工作或其他都可以），让它在解压出来的文件夹里把环境装好。

```text
请帮我在这台 Windows 电脑上安装 Node.js，使用不低于 22.13 的 LTS 版本。装好后，进入我解压出来的「简历专家」项目文件夹，运行 npm install。不要修改代码，也不要把任何 API Key 写进文件。
```

2. 双击文件夹里的 **启动简历专家.bat**。
3. 在弹出的小窗口里点 **开始**，浏览器会打开这个工具。
4. 用完点 **关闭**。直接关掉小窗口也可以，工具会一起停下来。

如果小窗口提示没有 Node.js 或没有安装依赖，把上面那段话交给助手处理，然后重新点 **开始**。

### Mac

Mac 上没有「开始 / 关闭」小窗口，可以让 AI 帮你在终端启动。

1. 在 Codex、豆包工作或其他 AI 助手中打开解压后的项目文件夹。
2. 粘贴下面整段提示词。
3. 启动后访问 [本地工具页面](http://127.0.0.1:5173/)。
4. 用完回到启动程序的终端，按 **Control + C** 停止服务。

```text
我在 Mac 上使用「简历专家」这个本地简历工具。请帮我完成这些事：
1. 如果还没有 Node.js，或者版本低于 22.13，请安装满足要求的 LTS 版本。
2. 进入我解压出来的项目文件夹，运行 npm install。
3. 运行 npm run dev:all，确认前后端正常启动。
4. 告诉我如何在浏览器打开 http://127.0.0.1:5173/，以及用完后怎么按 Control + C 停掉。

不要修改项目代码，也不要把任何 API Key 写进文件。
```

熟悉命令行的话，也可以自己运行：

```sh
npm install
npm run dev:all
```

## 🔑 配置 API

网页右上角点击 **设置 API**，填写你使用的模型服务配置。

以 DeepSeek 为例：

| 填写项 | 内容 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com` |
| 模型名称 | 填写 DeepSeek 开放平台当前提供、且你的账号可调用的模型 ID |
| API Key | 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 申请后，自行粘贴 |

地址填到域名或 `/v1` 为止，不要带 `/chat/completions`。其他服务请使用该服务提供的兼容接口地址和模型 ID；模型名称以服务商控制台为准。

先点 **检测连接**，看到成功后再点 **保存**。配置保存在本机，页面不会回显完整密钥。进行分析时，后端会使用密钥调用你指定的模型服务。

## 📄 准备简历和岗位要求

当前通过 **粘贴文本** 输入材料，支持普通文本和 Markdown，暂不支持直接上传 Word 或 PDF。建议用标题和列表整理简历，便于检查内容。

Markdown 是一种纯文字格式，用 `#` 当标题，用 `-` 当列表。你可以自己整理，也可以让信任的 AI 工具只换格式。若使用其他服务转换，请自行决定是否向其提供简历中的个人信息。

```text
请把我下面贴出的简历原样转换成 Markdown。
要求：
- 只做格式转换，不要改写、不要润色、不要删减
- 保留原来的公司、岗位、时间、项目和数字
- 用标题和列表排好，方便我复制
- 只输出 Markdown 正文，不要解释

简历正文从这里开始：
```

把结果贴进 **原始简历**，岗位要求贴进 **目标校招岗位 JD**。

## ✍️ 开始改简历

1. 填写简历名称和版本，例如「数据分析实习简历」「V1」。
2. 选好目标岗位、行业、公司类型和投递场景，补齐页面要求的信息。
3. 粘贴 JD 和原始简历。可选的经历材料尽量填写，分析会更有依据。
4. 点 **开始分析**，查看 JD 解析、简历诊断、经历匹配和修改策略。
5. 按追问补充真实经历，再进行深度优化，查看改写对照、最终简历及面试建议。
6. 可以导出 Markdown 报告，也可以点 **下载完整报告备份** 保存 JSON 文件。JSON 备份目前用于留存，未提供导入入口。

模型建议需要你核实。不要把待确认的数字、经历或成果直接当作事实写进简历。

## 🕘 查看历史分析

**初始分析成功后，报告会自动保存到本机。** 后续的深度优化结果和已评价的模拟面试回答也会关联到这条记录。

点击顶部 **历史分析**，可以：

- 按时间倒序查看过去的分析。
- 按日期范围、目标岗位、简历版本筛选。
- 点 **查看完整报告**，重新查看当时的输入、评分、问题和建议。
- 删除不需要的记录。
- 选择一条历史记录，作为新分析的参考或对比基准。

刷新页面、关闭工具或重启服务后，已保存的历史仍在。点击 **新会话** 会清空当前工作区，不会删除历史。

如果保存失败，页面会提示错误，并尽量把报告暂存在当前浏览器。重新打开网页后，可以 **恢复报告**、**重试保存**。重试保存不会再次调用模型，也不会重复新增记录；清理浏览器站点数据会删除尚未保存的暂存报告。

## 🧠 让工具记住你确认过的信息

点击顶部 **长期记忆**，可以保存求职目标、意向行业、真实实习经历、技能、认可的修改方向和求职偏好。

1. 选择类别，填写信息。
2. 勾选确认框，确认信息真实并同意用于后续分析。
3. 点 **保存记忆**。之后可以随时编辑或删除。

新一轮分析会读取已确认的信息，并检索与当前岗位相关的历史问题和优化方向，形成简短参考。它不会把所有历史对话塞进提示词，也不会把 AI 推测自动写成你的真实经历。

报告中的 **历史问题跟进** 可以标记自己已经修改的内容。这个标记属于你的自报状态，模型仍需要结合新版简历重新核实。

## 🔄 对比不同版本简历

1. 打开 **历史分析**，找到旧版简历。
2. 点击 **作为新分析参考 / 对比基准**。
3. 在输入区填写新版名称、版本和简历正文，检查目标岗位与 JD，再点 **开始分析**。
4. 在新版报告下方，点 **分析版本变化（调用模型）**。

对比会展示新增、删除和修改的内容，哪些历史问题已有证据支持解决，哪些仍然存在，以及下一轮建议。

同时展示 **岗位适配分、岗位匹配分** 的前后变化及依据，以及 11 项文字维度评价的变化。分数可以提高、保持不变或下降；岗位、JD、模型或评价标准不同，会提示可比性受限。评分只是模型判断，不代表录取概率。

## 🔒 数据放在哪里

- 历史报告、原始材料和长期记忆保存在本机 `data/resume-expert.sqlite`。
- API 设置保存在本机 `data/llm-settings.json`，包含你自行保存的密钥，请妥善保管。
- 分析时会将必要材料和有限历史参考发送给你配置的模型服务；本地保存不等于离线分析。
- 当前是 **本机单用户版本**。同一操作系统账户下的数据共用，没有多用户登录或云端同步。
- 数据库没有加密，请使用个人系统账户并保护电脑和备份文件。

删除历史会清理关联的问题和比较结果；你独立确认的画像信息需要在 **长期记忆** 页面单独删除。自己下载的报告备份也需要自行删除。

如果需要备份或迁移到另一台电脑，请先关闭工具，再备份 `data` 文件夹。里面可能包含简历和密钥，**不要上传到 GitHub 或公开分享**。

## 🌱 这一版还比较粗糙

界面和操作都比较简单，目前支持文本输入、Markdown 报告导出、JSON 报告备份，没有 Word / PDF 自动解析和精致排版导出。

欢迎二创 ✨。可以改进界面、导出格式和修改流程，也欢迎分享使用反馈。

## 💡 使用时注意

- 不要把 API Key、个人简历、历史数据库或日志提交到 GitHub。
- 新分析、深度优化、面试评价和版本变化分析会消耗模型额度；查看历史、编辑记忆和重试保存不会调用模型。
- 模型费用取决于服务商、模型和输入输出长度，Markdown 格式本身不能保证费用更低。
- 小窗口提示端口被占用时，先点 **关闭**，再点 **开始**。
- 这个版本不会自动替你投递简历，最终内容请自己核对。
